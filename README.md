# Hair Loss Tracker

A modern web application designed to help users track and monitor their hair health progress over time. Built with **React** and **Vite**, styled with **TailwindCSS**.

## 🌟 Features

- **Progress Tracking**: Log and monitor changes in hair density and health.
- **Visual History**: (Planned) Upload photos to create a timeline of your progress.
- **Modern UI**: Clean and responsive interface built with TailwindCSS.

## 🚀 Getting Started

### Prerequisites

- Node.js (v14+)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/hair-loss-app.git
   ```
2. Navigate to the project directory:
   ```bash
   cd hair-loss-app
   ```
3. Install dependencies:
   ```bash
   npm install
   ```

### Running Locally

Start the development server:

```bash
npm run dev
```

## 🛠️ Build

To build for production:

```bash
npm run build
```
